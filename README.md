# 🤖 Telegram-бот с нейросетью Gemini на серверах Google

Бот-собеседник в Telegram, как ChatGPT. Работает **бесплатно** и **круглосуточно** на
[Google Apps Script](https://script.google.com): без своего сервера, без банковской карты,
без установки программ. Мозги — нейросеть **Google Gemini**.

## Что умеет

- 💬 Отвечает на любые вопросы с помощью Gemini (по умолчанию — свежая `gemini-3.8-flash`)
- 🧠 Помнит контекст разговора: последние 20 сообщений, до 6 часов. Можно задавать уточняющие вопросы
- ✨ Аккуратно оформляет ответы: **жирный**, *курсив*, `код`, блоки кода, списки, цитаты и даже таблицы
- ✂️ Длинные ответы сам делит на несколько сообщений, не ломая блоки кода
- 👥 Работает в личке и в группах: отвечает на упоминание `@бота` или на ответ на его сообщение
- 🔁 Если у основной модели кончился бесплатный лимит, сам переключается на запасную
- 🔒 Можно закрыть доступ для чужих (`ALLOWED_USERS`)
- ⌨️ Команды: `/new`, `/help`, `/id`

## Как это работает

```
 Ты пишешь боту в Telegram
            │
            ▼
 Telegram пересылает сообщение в твой скрипт на серверах Google (вебхук)
            │
            ▼
 Скрипт отправляет диалог в нейросеть Gemini и получает ответ
            │
            ▼
 Скрипт отправляет ответ тебе в Telegram
```

### А как же «90 минут в день»?

В бесплатном Google Apps Script действительно есть лимит **«90 минут в день»**, но только на
**триггеры**, то есть автозапуски по расписанию. Наш бот триггерами не пользуется: Telegram сам
«будит» скрипт каждым новым сообщением (это и есть вебхук). Поэтому лимит в 90 минут к боту не
относится, и он отвечает **24/7**. На один ответ уходит несколько секунд.

Какие ограничения есть на самом деле — в разделе [«Лимиты»](#-лимиты-и-стоимость).

## 🚀 Запуск за 15 минут

Понадобятся только аккаунт Google (Gmail) и Telegram.

### Шаг 1. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай имя бота и username (он должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохрани его.

### Шаг 2. Получи бесплатный ключ Gemini

1. Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и войди Google-аккаунтом.
2. Нажми **Create API key** и скопируй ключ (начинается с `AIza...`).

> 🌍 Если сайт пишет, что в твоём регионе он недоступен, открой его через VPN. Это нужно
> один раз, чтобы получить ключ. Сам бот работает на серверах Google, и запросы к Gemini
> уходят оттуда, а не с твоего устройства.

### Шаг 3. Создай проект Apps Script

1. Открой [script.google.com](https://script.google.com) → **Создать проект** (New project).
2. Слева сверху нажми «Проект без названия» и назови его, например, «Gemini бот».
3. В файле `Code.gs` удали всё и вставь целиком содержимое файла [`src/Code.js`](src/Code.js)
   из этого репозитория (на GitHub есть кнопка **Copy raw file** 📋).
4. Сохрани: 💾 или `Ctrl+S`.

### Шаг 4. Добавь ключи в «Свойства скрипта»

1. Слева нажми ⚙️ **Настройки проекта** (Project Settings).
2. В самом низу: **Свойства скрипта** → **Добавить свойство скрипта**.
3. Добавь два свойства:

   | Свойство         | Значение                |
   |------------------|-------------------------|
   | `TELEGRAM_TOKEN` | токен от @BotFather     |
   | `GEMINI_API_KEY` | ключ из Google AI Studio |

4. Нажми **Сохранить свойства скрипта**.

> ⚠️ **Никогда не вставляй токены прямо в код и не загружай их на GitHub**: этот репозиторий
> публичный. Кто знает токен, тот управляет ботом.

### Шаг 5. Разверни скрипт как веб-приложение

1. Справа сверху синяя кнопка **Начать развертывание** (Deploy) → **Новое развертывание** (New deployment).
2. Рядом с «Выберите тип» нажми ⚙️ → **Веб-приложение** (Web app).
3. Заполни:
   - **Описание** — любое, например «бот»;
   - **Запуск от имени** (Execute as) — **Я** (Me);
   - **У кого есть доступ** (Who has access) — **Все** (Anyone). ❗ Это важно, иначе Telegram не достучится.
4. Нажми **Развернуть**. Google попросит разрешение: **Предоставить доступ** → выбери аккаунт.
   Если появится «Google не проверял это приложение», нажми **Дополнительные настройки** (Advanced)
   → **Перейти на страницу проекта** (Go to … (unsafe)) → **Разрешить**.
   > Это нормально: «приложение» здесь — твой собственный скрипт. Он просит всего одно разрешение:
   > подключаться к внешним сервисам (Telegram и Gemini).
5. Скопируй **URL веб-приложения**. Он заканчивается на `/exec`.

### Шаг 6. Добавь адрес в свойства

Снова ⚙️ **Настройки проекта** → **Свойства скрипта** → добавь ещё одно:

| Свойство     | Значение                                                   |
|--------------|------------------------------------------------------------|
| `WEBAPP_URL` | скопированный адрес `https://script.google.com/macros/s/…/exec` |

### Шаг 7. Запусти `setup`

1. Вернись в редактор (слева значок `< >`).
2. В выпадающем списке функций сверху выбери **`setup`** и нажми **Выполнить** (Run).
3. Внизу откроется журнал выполнения. Если всё в порядке, ты увидишь:

   ```
   1/4 Проверяю токен Telegram…
      ✅ Бот найден: @my_gemini_bot
   2/4 Проверяю нейросеть Gemini…
      ✅ Gemini отвечает (модель gemini-3.8-flash): Привет
   3/4 Подключаю бота к Telegram (вебхук)…
      ✅ Вебхук установлен
   4/4 Настраиваю меню команд…
      ✅ Готово
   🎉 Бот запущен! Напиши ему: https://t.me/my_gemini_bot
   ```

   Если что-то не так, в журнале будет прямо написано, что исправить.

### Шаг 8. Пиши боту! 🎉

|----------|-----------------------------------------------------------------|

## ⚙️ Настройки (по желанию)

Все настройки задаются в тех же **«Свойствах скрипта»**. Заново развертывать ничего не нужно:
изменения подхватываются со следующего сообщения.

| Свойство                 | По умолчанию | Что делает |
|--------------------------|--------------|------------|
| `SYSTEM_PROMPT`          | дружелюбный ассистент | Характер и правила бота. Новая строка — `\n` |
| `ALLOWED_USERS`          | пусто (всем)  | Кому можно пользоваться ботом: ID или `@username` через запятую. Можно указать ID группы |
| `GEMINI_MODEL`           | `gemini-3.8-flash` | Основная модель |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.6-flash, gemini-3.5-flash-lite, gemini-2.5-flash, gemini-flash-latest` | Запасные модели, по порядку |
| `THINKING_LEVEL`         | `low`         | Глубина «размышлений»: `minimal` / `low` / `medium` / `high`. Чем выше, тем умнее, но медленнее |
| `HISTORY_MESSAGES`       | `20`          | Сколько последних сообщений помнит бот (`0` — без памяти) |
| `HISTORY_TTL_HOURS`      | `6`           | Через сколько часов тишины память стирается (максимум 6) |
| `MAX_OUTPUT_TOKENS`      | `8192`        | Максимальная длина ответа |
| `TEMPERATURE`            | (решает модель) | Креативность от 0 до 2. Для Gemini 3 Google советует не трогать |
| `TIMEZONE`               | пояс проекта  | Например, `Europe/Moscow`, чтобы бот знал точное время |

Служебные свойства `WEBHOOK_SECRET`, `BOT_USERNAME` и `BOT_ID` заполняет сам `setup()`. Их не трогай.

**Пример: бот-персонаж**

```
SYSTEM_PROMPT = Ты — весёлый пират по имени Джек. Отвечай коротко, с пиратскими словечками, но по делу.
```

## 🔄 Как обновить код

Если ты поменял код в редакторе, бот продолжит работать на старой версии, пока ты не выпустишь новую:

1. **Начать развертывание** → **Управление развертываниями** (Manage deployments).
2. ✏️ **Изменить** → в поле «Версия» выбери **Новая версия** → **Развернуть**.

Адрес останется прежним, больше ничего делать не нужно.

> ❗ Не создавай каждый раз **новое** развертывание: у него будет новый адрес. Если всё же создал,
> обнови `WEBAPP_URL` и снова запусти `setup()`.

## 👥 Бот в группе

1. Добавь бота в группу.
2. Обращайся к нему так: `@имя_бота вопрос`, или ответь (reply) на его сообщение. Команды пиши
   так: `/new@имя_бота`.
3. Бот видит только сообщения, обращённые к нему (это режим приватности Telegram, так задумано).
   История в группе общая, и бот знает, кто что написал.

## 📊 Лимиты и стоимость

Всё бесплатно. Ограничения такие:

- **Gemini (бесплатный тариф).** У каждой модели есть лимит запросов в минуту и в день. Свои
  точные цифры смотри в [AI Studio](https://aistudio.google.com/rate-limit). Когда лимит одной
  модели кончается, бот переключается на запасную. Дневные лимиты обнуляются в полночь по
  тихоокеанскому времени (около 10–11 утра по Москве).
- **Google Apps Script** (обычный аккаунт Gmail): до 20 000 внешних запросов в сутки (один ответ
  бота — примерно 3 запроса, то есть тысячи ответов в день), до 30 одновременных выполнений и
  не больше 6 минут на одно выполнение. Лимит «90 минут» на триггеры боту не мешает (см. выше).
- **Конфиденциальность.** На бесплатном тарифе Google может использовать запросы для улучшения
  своих продуктов. Не отправляй боту пароли и личные данные.

## 🛠 Если что-то не работает

Сначала запусти функцию **`status()`**. Она покажет, подключён ли бот, последнюю ошибку и подсказку, как её исправить.

| Проблема | Что делать |
|----------|------------|
| Бот молчит | Запусти `status()`. Частые причины: не запущен `setup()` или в развертывании выбран доступ не «Все» |
| Поменял код, а бот ведёт себя по-старому | Выпусти новую версию развертывания (см. [«Как обновить код»](#-как-обновить-код)) |
| «Нейросеть занята: закончился бесплатный лимит» | Подожди минуту (если кончился минутный лимит) или до завтра (если дневной) |
| «Бот настроен неправильно» | Проверь `GEMINI_API_KEY` и снова запусти `setup()` |
| `setup()`: «WEBAPP_URL выглядит неправильно» | Нужен адрес `…/exec` из окна развертывания, а не адрес редактора |
| Где смотреть ошибки? | В редакторе слева **Выполнения** (Executions): там журнал по каждому сообщению |
| Как выключить бота? | Запусти `stopBot()`. Включить обратно — `setup()` |

## 👨‍💻 Для разработчиков

```
src/Code.js          — весь код бота (в редакторе Apps Script это файл Code.gs)
src/appsscript.json  — манифест: среда V8, доступ к веб-приложению, разрешения
tests/               — тесты на Node.js с заглушками сервисов Apps Script
```

**Тесты** (Node.js 22+, без зависимостей):

```bash
npm test
```

**Деплой из терминала через [clasp](https://github.com/google/clasp)** (по желанию, вместо копирования кода):

```bash
npm install -g @google/clasp
clasp login                          # перед этим включи Apps Script API: https://script.google.com/home/usersettings
cp .clasp.json.example .clasp.json   # и впиши scriptId: ⚙️ «Настройки проекта» → «Идентификатор скрипта»
clasp push                           # загрузить код в проект
clasp list-deployments               # узнать ID развертывания
clasp update-deployment <ID>         # выпустить новую версию по тому же адресу
```

**Идеи для развития:** понимание фото и голосовых (Gemini это умеет), постоянная память в
Google Таблице, лимит сообщений на пользователя.
